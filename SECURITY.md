# Security policy

Context Passport handles potentially sensitive transcripts and Git changes. Treat generated handoffs as private until you review them.

Version 0.1 is an early release. Redaction is a best-effort convenience, not a guarantee that data is safe to share. See [the privacy model](docs/PRIVACY.md).

## Reporting

Use GitHub's **Security → Report a vulnerability** on this repository when private reporting is available. If that control is unavailable, open an issue with only a request for a private contact method. Do not include secrets, private exports, or exploit payloads containing real data in a public issue.

A report should include the affected version, operating system, a minimal synthetic reproduction, and impact. Do not use this tool to test repositories or data you are not authorized to access.

No response-time SLA or paid audit is claimed.
