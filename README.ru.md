# Context Passport

**Меняйте AI-инструменты, не объясняя задачу заново.**

[English](README.md) · [简体中文](README.zh-CN.md) · [Русский](README.ru.md)

Context Passport превращает выбранный вами диалог Claude, Claude Code, Codex, ChatGPT или текстовый журнал в проверяемый пакет передачи работы: цель, решения, заявления о выполненной работе, препятствия, следующие шаги, записанные команды тестов и необязательный снимок Git. Для каждого пункта сохраняется ссылка на источник.

Обработка выполняется локально без сетевых запросов. Во время работы используется только стандартная библиотека Python. Не нужны API-ключ, подписка на модель, база данных или аккаунт. Требуется Python 3.10+; Git нужен только для параметра `--repo`.

## Установка и демонстрация

```bash
pip install "git+https://github.com/PedramNoSkill/context-passport.git"
context-passport demo --out ./passport-demo
```

Откройте `passport-demo/review.html` в браузере. Страница работает офлайн. Диалог и исторический вывод тестов в демонстрации — **явно помеченные вымышленные примеры**; сами файлы создаёт настоящий CLI.

Эта версия устанавливается из GitHub. Публикация в PyPI пока не выполнена.

## Создание пакета

```bash
passport create \
  --from ./session.jsonl \
  --repo ./my-project \
  --target codex \
  --title "Завершить локальный поиск" \
  --next "Исправить сообщение о пустом результате и повторить тесты." \
  --out ./my-passport
```

- `--from`: конкретный локальный файл, выбранный вами. Автоматического поиска чужих диалогов нет.
- `--repo`: необязательный путь к рабочему дереву Git. Без него Git не читается.
- `--no-diff`: только пути изменённых файлов, без текста различий.
- `--conversation`: точный ID или уникальное название диалога в экспорте с несколькими беседами.

Будут созданы три файла:

- `HANDOFF.md` — материал для следующего ассистента.
- `passport.json` — структурированные данные с версией схемы.
- `review.html` — офлайн-страница проверки с поиском по источникам.

```bash
passport inspect ./my-passport
passport prompt ./my-passport --target claude
passport conversations ./conversations.json
```

Передайте Markdown следующему инструменту самостоятельно. Программа не входит в Claude/Codex и не внедряет контекст в другие приложения.

## Сначала источники

Извлечение буквальное и детерминированное — **это не LLM-суммаризатор**. Явные метки `Goal:`, `Decision:`, `Done:`, `Next:` и `Blocked:` попадают в разделы. Также распознаются `Цель:`, `Решение:`, `Готово:`, `Далее:` и `Препятствие:`. Остальной текст остаётся доступным в исходных свидетельствах.

Добавляйте собственные заметки через `--goal`, `--decision`, `--done`, `--next` и `--blocker`. По умолчанию целью становится первое сообщение пользователя; `--goal` заменяет его.

Фраза ассистента «все тесты прошли» не считается доказательством запуска. Нужны связанный вызов инструмента, его результат и код выхода. Нулевой код описывает записанный результат команды, а не гарантирует качество тестов или состояние текущей версии.

Снимок Git только читается: код проекта не запускается, содержимое неотслеживаемых файлов не читается, коммиты и push не выполняются. Известные файлы с секретами и содержимое символических ссылок исключаются из diff.

## Проверяйте перед отправкой

Перед записью распространённые секреты заменяются маркерами: приватные ключи, известные форматы токенов, заголовки авторизации, учётные данные в URL и присваивания паролей. **Обнаружение выполняется по возможности и не даёт гарантии.** Имена файлов, деловая информация и код всё ещё могут быть чувствительными. Проверяйте все три файла; подробности — в [модели приватности](docs/PRIVACY.md).

Версия 0.1 — файловая передача контекста. Здесь нет автоматической синхронизации приложений, фоновой долговременной памяти, MCP-сервера или LLM-обобщения.
